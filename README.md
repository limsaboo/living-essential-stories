# 『살아가며 꼭 필요한 이야기들』 원고실

이 저장소는 임박사의 도서 『살아가며 꼭 필요한 이야기들』을 위한 독립 원고실입니다.

## 저장소 정보
- GitHub 저장소: `limsaboo/living-essential-stories`
- 저장소 주소: https://github.com/limsaboo/living-essential-stories
- 공개 범위: Public
- 기본 브랜치: main
- 원고 위치: 저장소 최상위(root)
- 기존 원고 보관소: `limsaboo/lim-book-library` (별도 비공개 저장소)

## 프로젝트 상태
기획 및 자료 수집 단계입니다. 기획서와 목차는 초안이며, 임박사의 검토 전까지 확정본으로 간주하지 않습니다.

## 현재 파일 구성
- 00-도서-기획서.md: 도서 기획 및 편집 원칙
- 01-전체-목차.md: 전체 목차 초안
- 02-프롤로그.md: 프롤로그 집필 방향
- 03-원고-01-아침습관과-건강.md: 첫 번째 장 초안 메모
- 04-유튜브-소재-분석대장.md: 영상 소재 및 주장 검토 기록
- 05-참고문헌-및-출처.md: 참고문헌·출처 관리
- 06-집필-진행현황.md: 집필 진행 현황
- README.md: 프로젝트 안내

## 작업 원칙
1. 유튜브 영상은 소재 발굴의 출발점으로만 사용합니다.
2. 영상의 주장과 과학적 근거를 분리해 검증합니다.
3. 근거가 부족하거나 확인되지 않은 내용은 사실처럼 쓰지 않습니다.
4. 타인의 표현을 그대로 옮기지 않고 독립적인 관점과 문장으로 재구성합니다.
5. 연구 결과는 대상, 조건, 한계와 함께 설명합니다.
6. 참고문헌, URL, 확인 날짜를 기록합니다.
7. 기존 비공개 원고 보관소의 자료는 이 저장소와 분리해 관리합니다.

## 첫 번째 소재
- 영상 제목: 65세 이후 30년의 수명을 결정짓는 운명의 아침 습관 | 충격적인 설명
- URL: https://youtu.be/CDmhEWhdb9A
- 제공된 요약에는 6가지 습관이라고 되어 있으나 실제 목록은 5개뿐입니다.
- 확인된 목록: 미지근한 물 500mL, 아침 햇빛, 단백질 30g, 균형운동, 4-7-8 호흡
- 여섯 번째 습관은 원자료 확인 전까지 임의로 보충하지 않습니다.
- 수명 30년 결정, 생물학적 나이 10년 회복 등의 주장은 검증 없이 사실로 사용하지 않습니다.
