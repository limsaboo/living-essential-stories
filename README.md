# 『살아가며 꼭 필요한 이야기들』 원고 프로젝트

- 프로젝트 상태: 기획 및 자료 수집 단계
- 원고 저장소: `limsaboo/lim-book-library`
- 업로드 위치: `02-살아가며-꼭-필요한-이야기들/`
- 원칙: 기존 도서 폴더와 원고는 수정하지 않는다.

## 작업 원칙
1. 유튜브 영상은 소재 발굴의 출발점으로만 사용한다.
2. 영상의 주장과 과학적 근거를 분리해 검증한다.
3. 근거가 부족하거나 확인되지 않은 내용은 사실처럼 쓰지 않는다.
4. 타인의 표현을 요약·재구성하되 독립적인 관점과 문장으로 집필한다.
5. 참고문헌, URL, 확인 날짜를 기록한다.

## 현재 첫 번째 소재
- 영상 제목: 65세 이후 30년의 수명을 결정짓는 운명의 아침 습관 | 충격적인 설명
- URL: https://youtu.be/CDmhEWhdb9A
- 제공된 요약에는 6가지 습관이라고 되어 있으나 실제 목록은 5개뿐이다.
- 확인된 목록: 미지근한 물 500ml, 아침 햇빛, 단백질 30g, 균형운동, 4-7-8 호흡
- 여섯 번째 습관은 원자료 확인 전까지 임의로 보충하지 않는다.
